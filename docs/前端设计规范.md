## 1. 设计定位

**产品**：本地常驻的私人音乐库控制台——一个人、一台服务器、一个自己的曲库。**主要任务**：把 Telegram 频道里的音频按自己的命名规则稳落到本机磁盘，之后还能找到它、播它、确认它在不在。

设计身份由三件事构成，其余全部克制：

1. **亮绿是唯一的「在做」信号**——主按钮、激活导航、播放主键、进度填充。全站只有一个强调色，不引入第二套。
2. **卡片化的事实分区**——页面底薄荷、卡片纯白并浮起（`--card-shadow`）、淡绿只出现在「正在发生」的面板（传输状态卡）与「已被选中」的导航项上。颜色永远表达状态或层级，不表达装饰。
3. **波形进度**是这一屏的签名元件——底部播放条用纵向声波柱代替线条，它是全站唯一「可以被记住」的形状。

不做：营销 hero、渐变/发光装饰、逐卡入场动画、SVG 插画（空态大图标除外）、第二强调色、设计稿之外的颜色。

## 2. 布局与栅格

### 2.1 总体架构

四段固定结构，路由只换主内容区（`App.svelte` = 侧栏 + 顶栏 + 内容出口 + 播放条）：

```
┌──────────┬──────────────────────────────────────────────────────┐
│          │ 仪表盘            [🔍 搜索…            Ctrl K]  ☾ 🔔 ⬤ │ 顶栏 64px（sticky）
│ ▣ 音乐库 ├──────────────────────────────────────────────────────┤
│ telegram │ 仪表盘                                               │
│ -music   │ 本地曲库与传输的实时状态。                            │ 页头：H1 + 一行上下文
│          │ ┌ 淡绿状态卡 ────────────────────────────────────┐   │
│ ▣ 仪表盘 │ │ ✓ 正在写入                     24px 卡片内边距 │   │
│  搜索    │ │ 现在没有传输，队列空着。        [去搜索] 按钮  │   │
│  下载任务│ │ 推荐搜索 #data #download                       │   │
│  下载历史│ │ /data/downloads/周杰伦/叶惠美/03 晴天.flac     │   │ 路径框
│  音乐源  │ └────────────────────────────────────────────────┘   │
│  设置    │ ┌ 曲库 ──────────────────── 共 5 首  查看全部 → ┐   │
│  日志 ⑥  │ │ # 标题/路径 ⟡ 时长 大小              ⋮        │   │ 表格卡片
│          │ └────────────────────────────────────────────────┘   │
├──────────┴──────────────────────────────────────────────────────┤
│ ♪ 夜的第七章  ⤨ ⏮ ▶ ⏭ ⟳  00:02 ▮▮▮▯▯▯▯ 04:03  🔊 ▮▮▯ ≡      │ 播放条 76px（fixed）
└─────────────────────────────────────────────────────────────────┘
```

- **侧栏**：`fixed`，宽 230px，全高，底 `--card`（白），右边 1px `--border`。
- **顶栏**：`sticky top-0`，高 64px，底 `--card`（**不透明**，不用 `backdrop-blur`：滚动性能优先），下边 1px `--border`。
- **内容区**：`max-w-[1100px]` 左对齐，内边距 24px；底部预留 `76px` 播放条高度 + 24px。
- **播放条**：`fixed bottom-0`，高 76px，全宽，底 `--card` + 上边 1px `--border`；全站唯一常驻浮层，切页不销毁。

### 2.2 间距令牌

| 档位 | 值 | Tailwind | 用途 |
| --- | --- | --- | --- |
| 页面外边距 | 24px | `p-6`（<768px `p-4`=16px） | 内容区外边距 |
| 卡片内边距 | 24px | `p-6`（紧凑卡片 `p-5`=20px） | 卡片内边距 |
| 区块间距 | 24px | `gap-6`（窄屏 `gap-4`） | 区块之间 |
| 列表项间距 | 12px | `gap-3` | 列表项、卡片内纵向节奏 |
| 行内间距 | 8px | `gap-2` | 图标↔文字、标签组、按钮组 |

间距直接使用 Tailwind 4 的 4px 基准刻度，**不在 `app.css` 里另立 `--space-*` 令牌**；上表只是把数值钉死，避免各处自选。表格行**不用** `gap`，用 1px 分割线 + 固定行高（§5.4）。

### 2.3 圆角令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--radius-card` | 16px | 大卡片、容器、浮层菜单、状态卡 |
| `--radius-nav` | 12px | 导航项选中块、表格卡片内的次级块 |
| `--radius-control` | 10px | 输入框、按钮、路径框、下拉 |
| `--radius-chip` | 8px | 标签 chip、徽章、封面缩略图、小图标按钮 |
| `--radius-pill` | 999px | 播放主键、头像、搜索框、状态点、进度条 |

`app.css` 的 `@theme inline` 把五个令牌注册为 `rounded-card / rounded-nav / rounded-control / rounded-chip`（`--radius-pill` 直接用 `rounded-full`）。shadcn 的 `--radius` 保留并设为 `10px`（= `--radius-control`），使 `ui/` 生成物的 `rounded-md/lg` 自动落在本尺度上。

`ui/` 生成物的落点钉死如下（生成物可改样式、勿改 API）：**浮层与容器**（`dialog-content`、`dropdown-menu-content`/`sub-content`、`select-content`）一律 `rounded-card`，不得沿用 shadcn 默认的 `rounded-xl/lg`——它们在本尺度里是 12px/10px，会把浮层做成比卡片还方的块；**控件**（`input`、`textarea`、`button`、`select-trigger`）保持 `rounded-lg`（= 10px）；**复选框**用最小的 `rounded-sm`（6px，`app.css` 已留存该令牌供 shadcn 的 `rounded-sm` 落点），**开关/开关把手/药丸件**用 `rounded-full`。除此之外不得出现 `rounded-[4px]` 这类令牌外字面量。

### 2.4 卡片浮起

卡片 = `--card` 底 + 1px `--border` + `--card-shadow`（极浅双层投影）。三项都在 `app.css` 的 `.card` 工具类里落地，页面不得自行加阴影或改圆角：

| 令牌 | 浅色 | 深色 |
| --- | --- | --- |
| `--card-shadow` | `0 1px 2px rgb(16 24 40 / 0.05), 0 14px 30px -22px rgb(16 24 40 / 0.28)` | `0 1px 2px rgb(0 0 0 / 0.45), 0 14px 30px -22px rgb(0 0 0 / 0.7)` |

浮层（`dialog` / `dropdown-menu` / `select`）沿用 shadcn 的 `shadow-md` / `shadow-lg`，不并入本令牌；`--background` 换薄荷底后，凡「浮在卡片上」的件不得再用 `bg-background` 取底色（outline 按钮取 `--card`、开关把手取 `--card`）。

## 3. 色彩系统（设计令牌）

颜色只表达**状态**或**层级**。页面里不得出现本节令牌以外的颜色——包括 Tailwind 调色板直取（`bg-red-500`、`text-gray-400`）。

| `--card` / `--popover` | `#FFFFFF` | `#18211D` | 卡片、顶栏、侧栏、播放条、浮层 |

| `--faint-foreground` | `#7C8797` | `#7C867F` | 时长、大小、单位、辅助说明（✱ 仅限冗余字段） |
| `--primary` | `#0B7A55` | `#4FB08A` | 主按钮底、激活导航文字/图标、播放主键、进度已播放段 |

### 3.2 深色态是派生态，不是第二套设计

浅色为默认主题（`index.html` 首帧内联脚本：`tgm-theme` 为 `dark` 或系统深色时才给 `<html>` 加 `.dark`）。深色态**只覆盖 §3.1 同一批令牌**，色相与语义角色不得改变，不得新增令牌。上表深色列是 §3.1 浅色值的机械派生：底色由薄荷转深绿灰（`#101613`），主色提亮到 `#4FB08A` 并配深色前景 `#06120C`（v3.0 的 `#3E9C76` 于 `--primary-soft` 底只有 **4.38:1**，低于 4.5 底线，v3.1 一并修掉）；`--destructive` 族取自 v2.0 已有的 `#FF6B6B`/`#DC7159` 家族，避免新增色相。

### 3.3 对比度底线（不是建议）

- 正文与关键副文本 ≥ 4.5:1；非文本控件（图标、状态点）≥ 3:1。
- 实测（v3.1 配色，浅色 / 深色）：`--primary` 于卡片底 **5.34 / 6.21:1**、于 `--primary-soft` 底 **4.69 / 5.57:1**；主色底上的文字 **5.34:1**（白）/ **7.19:1**（深色 `#06120C`），hover 底 **6.53 / 7.26:1**；`--muted-foreground` 于卡片 **5.98 / 6.52:1**、于薄荷底 **5.43 / 7.25:1**、于 `--primary-surface` 底 **5.32 / 6.40:1**；`--destructive-text` 于白底 **4.98:1**；`--destructive`（非文本）于白底 **3.71:1**；状态灯 `--lamp-done` **5.33 / 7.32:1**、`--lamp-idle` **3.64 / 4.37:1**（非文本，达标）。
- **`--faint-foreground`（`#7C8797`）于白底 3.64:1，不达 AA**——故它只用于**冗余**字段（时长、大小、单位：同一信息在别处仍可得），路径与歌手这类关键信息一律用 `--muted-foreground`。
- **`--border` / `--input`（`#E5E6EB`）于白底仅 1.25:1，低于 WCAG 1.4.11 对控件边界的 3:1**——这是与参考图一致的**有意取舍**：卡片的可辨识性由「薄荷底 ↔ 白卡」的明度差加 `--card-shadow`（§2.4）承担，描边只做收边。若要严格达标，把 `--border` 提到 `#8A93A2`（3:1）会把整屏线条明显加重，本版不采用。
- 浅绿（`--primary-soft` / `--primary-surface`）**只做底**，不得作为文字色或图标色。

### 3.4 落盘路径的排法

路径是产品承诺的物证，是列表行里的**一级文本**（第二行），不是脚注：

- 用 `splitPath()` 拆成「目录」+「文件名」两段：目录段 `truncate` 可省，**文件名段 `shrink-0`、永不被省略号吃掉**（扩展名是曲库的判断依据）。
- 整条路径挂 `title` 属性，悬停可见全量；「复制路径」给的是原文，不是省略后的显示值。
- 样式：`text-code`（12px `--font-mono`）+ `--muted-foreground`，单行。
- 文件不在磁盘时，这一行**整体替换**为 `--destructive-text` 的原因文案（§5.4）。

## 4. 字体与排版

### 4.1 字体族

| 令牌 | 值 | 说明 |
| --- | --- | --- |
| `--font-sans` | `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif` | 全部界面文字 |
| `--font-mono` | `"DM Mono", ui-monospace, "Cascadia Mono", Consolas, monospace` | 路径、id、日志、字节原文 |

- Inter 经 `@fontsource-variable/inter` **自托管**（沿用「局域网离线可用、不外链 CDN」原则）；`@fontsource-variable/archivo` 从依赖中**移除**。
- CJK 不引入 webfont，回落系统字体（体积与时延不值当）。DM Mono 保留（已在依赖内，400/500）。
- **数字对齐**：时长、大小、速率、时间码一律 `tabular-nums`（Inter 原生支持），右对齐；只有**字符串型机器数据**（路径、id、日志）才用 `--font-mono`。工具类 `.tabular` = `font-variant-numeric: tabular-nums`。

### 4.2 层级

| 令牌 | 字号 / 行高 / 字重 | 用途 |
| --- | --- | --- |
| `text-h1` | 24px / 1.3 / 700 | 主页面大标题（「搜索结果」「仪表盘」） |
| `text-h2` | 18px / 1.4 / 600 | 区块/卡片标题（「曲库」「正在写入」） |
| `text-body` | 14px / 1.5 / 400（导航项与按钮 500） | 歌名、按钮文字、导航项、正文 |
| `text-caption` | 12px / 1.5 / 400 | 歌手、时长、大小、表头、徽章、辅助说明 |
| `text-code` | 12px / 1.4 / 400 + `--font-mono` | 文件路径、id、日志行 |

### 4.3 规则

- 五个排版令牌即全部层级，`app.css` 的 `@theme inline` 注册为 `text-h1/h2/body/caption/code`；不写 `text-[13px]` 这类一次性字号。
- 中文段落行宽 ≤ 40 汉字；英文/路径 ≤ 80ch。
- 一个字符串只做一件事：标题内不得对单个词加粗/变色强调。

## 6. 交互状态与反馈

### 6.1 空状态

- 组成：占位大图标（48px，`--faint-foreground`）+ 引导文案（14px，`--muted-foreground`）+ 出口按钮。
- 文案说清下一步动作，不卖萌、不空泛：任务页「队列空着。把链接粘到上面的输入框，或在搜索页挑一首。」；历史页「还没有入库的曲目。搜索并下载第一首。」；搜索页「没找到匹配的曲目。换个关键词，或换一个已启用的音乐源。」；日志页「本次连接没有错误。」
- 组件：`EmptyState.svelte`；插画不做（除了一个图标，不进图）。

### 6.2 点击反馈

- Hover：`opacity: 0.85` **或**背景加深——导航项/列表行/图标键用**背景加深**（`--rule`），主按钮用 `--primary-hover`，链接用 `--primary-hover` 文字。
- Active：`transform: scale(0.98)`，仅用于按钮与图标键，130ms。
- 过渡：`transition: background-color 130ms ease-out, color 130ms ease-out`；`scale` 只走 `transform`（不触发 layout）。
- 禁用：`opacity: 0.5` + `cursor: not-allowed` + 不响应事件（含 `aria-disabled`）。
- 行内反馈紧贴触发控件用 `Note`（左侧 2px 色条），**不用 toast**；错误说原因与修复，成功说清改了什么。

### 6.3 响应式断点

| 断点 | 侧栏 | 顶栏 | 内容/表格 | 播放条 |
| --- | --- | --- | --- | --- |
| ≥1024px | 230px 展开 | 标题 + 搜索（最大 480px）+ 全部工具 | `max-w-[1100px]`；显示全部列 | 三分区完整 |
| 768–1023px | 64px 图标模式 | 搜索收窄至 320px；隐藏页面标题 | 隐藏「大小」列 | 右区收为音量图标（点击弹滑块） |
| <768px | 收进顶栏汉堡抽屉（`MobileNav.svelte`） | 搜索收为图标（点开全宽浮层） | 隐藏「大小」「入库时间」；保留「标题」+「时长」 | 封面 + 歌名 + 播/停；进度条贴底 2px 不可拖 |
| 390px（验收基准） | 抽屉 | 图标化 | 单列、无横向滚动；卡片内边距 16px | 同上 |

- 列隐藏用 CSS（Tailwind 断点类），**不改变数据获取**；路径第二行在任何断点都保留（靠省略号，不靠隐藏）。
- 卡片内边距与区块间距在 `<768px` 降到 16px（§2.2）。

## 7. 可访问性与动效

- **焦点**：`outline: 2px solid var(--ring)` + `outline-offset: 2px`；键盘可见焦点不得被 `overflow` 裁掉。
- **键盘**：顶栏搜索 `Ctrl/⌘+K` / `Esc`；音量与播放位置用原生 `input[type=range]` 的方向键行为；抽屉与浮层 `Esc` 关闭并把焦点还给触发键。
- **图标按钮一律 `aria-label`**；纯装饰元素 `aria-hidden="true"`。
- **状态不只靠颜色**：一律「灯 + 词」（8px 圆点 + 文字，§8），错误行除红色外必须带文字原因。
- **对比度**：见 §3.3（含实测值与 `--faint-foreground` 的使用限制）。
- **动效只有三处**：hover/active 过渡 130ms、路由内容整体淡入 140ms（`route-fade`，仅 `opacity`）、进行中状态点呼吸 1.6s（`ladder-pulse` 改名 `dot-pulse`）。`prefers-reduced-motion: reduce` 时全部关闭（含 shadcn 自带过渡）。

## 8. 状态语义与文案

状态一律「**灯 + 词**」（8px 圆点 + 文字），禁止仅用颜色表达状态；计数徽章 §5.1 用浅绿药丸，**不是**状态灯。

| 后端状态 | 灯色令牌 | 词（zh-CN） |
| --- | --- | --- |
| `queued` | `--lamp-idle`（`#7C8797`） | 等待 |
| `downloading` | `--lamp-live`（= `--primary`，呼吸） | 下载中 |
| `paused` | `--lamp-wait`（`#5B6472`） | 已暂停 |
| `success` / `skipped` | `--lamp-done`（`#1C7A4E`；与 `--lamp-live` 同色系，靠「灯 + 词」的**词**区分） | 完成 / 跳过 |
| `failed` | `--lamp-fail`（= `--destructive`） | 失败 |
| `cancelled` | `--lamp-idle` | 已取消 |

映射表只有一处实现：`web/src/lib/tone.ts`（`taskTone()` / `statusText()`），页面不得自行发明颜色或状态词。`--lamp-live/done/fail/wait/idle` 五个令牌保留（值随 §3 调整），深色态同步覆盖。

**文案规则**（文案是设计内容，不是装饰）：

1. 主动词、说结果：按钮「保存更改」→ 提示「已保存」；「加入队列」→「已加入 2 项」；禁「提交」。
2. 空态是邀请：说清下一步动作 + 给出口按钮（§6.1）。
3. 错误说原因与修复，不道歉、不含糊：「源无法访问：先用该账号加入频道，再重试。」「文件大小不符：期望 … 字节，实收 … 字节」。
4. 术语用**用户视角**的词：音乐源、落盘路径、试听、下载历史；不暴露内部实现（`sync_interval_sec`、`preview_id` 只出现在设置项与技术字段处）。
5. 全部文案走 `t("namespace.key")`（`lib/i18n/messages.ts`，zh-CN 默认 + en），组件内禁硬编码中英文案；缺键回落英文再回落键名，便于发现漏配。

## 9. 工程约束

- 组件 `<script lang="ts">` + Svelte 5 **runes**（`$state/$derived/$effect/$props/$bindable`）；禁 `on:click` 旧语法、禁 `export let`。
- TS `strict`，禁 `any`（确需用 `unknown` + 收窄）。
- API 只经 `src/lib/api/client.ts`；组件内禁裸 `fetch`。
- SSE 只在 `stores/events.svelte.ts` 订阅一次；任务列表事实源是 DB（`GET /api/downloads`），SSE 只作失效信号（另有 10s 兜底轮询）。
- 样式：Tailwind utility + §3/§2.3/§4 的令牌；禁行内样式（动态尺寸/颜色除外）；**禁令牌外颜色**（含调色板直取）。
- 令牌落地方式：`app.css` 中 `:root`（浅色默认）+ `.dark`（派生覆盖）+ `@theme inline` 映射为 utility（`bg-card`、`text-h1`、`rounded-card`、`text-caption`…）。v2.0 的 `--rule-strong`、`--meter-on/off`、`--text-micro/small/title/display` 一并删除。
- 体积与性能：不引入图形/动画库；波形为 CSS 绘制；顶栏不做 `backdrop-blur`；进度与音量共用一个 range 内核。
- 组件命名 PascalCase 多词；`ui/` 为 shadcn-svelte 生成物（可改样式、勿改 API）。
- 时间/大小/速率一律走 `lib/format.ts`；状态词一律走 `statusText()`。
- `npm run lint`（eslint + svelte-check）与 `npm run build` 必须干净。
- 初始化向导（`SetupView`）是全屏闸门，不套侧栏/顶栏/播放条。闸门在**渲染期**判定：`setupGate = session.checked && !session.setup?.complete` 为真时整页只渲染向导（控制台一帧都不渲染），并把地址栏 replace 成 `/setup`；`/api/setup/status` 没取到（后端未起、401）也算未完成——首次部署只有向导这一个入口，宁可在向导里写明原因，也不要有永久加载态或用不了的控制台。
