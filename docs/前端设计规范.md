## 1. 设计定位

本地常驻的私人音乐库管理台。用户在终端与编辑器之间工作，核心动线：搜索 → 试听 → 下载 → 按模板落盘。设计隐喻是**精密音响面板**：冷静、信息密度可控、一个浓墨重彩的显示区（播放条），其余克制。

不做：营销页 hero、卡片瀑布流、渐变装饰。

## 2. 设计令牌（CSS 变量）

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--bg-base` | `#101418` | 页面底（冷调近黑，衬 Telegram 蓝体系） |
| `--bg-raise` | `#1A2026` | 浮起面板/侧栏/列表行 hover |
| `--bg-inset` | `#151A20` | 输入框、播放条底 |
| `--ink-hi` | `#E8ECF0` | 主文本 |
| `--ink-mid` | `#8A98A6` | 次文本、标签 |
| `--accent` | `#4FA3E3` | 唯一强调色：当前页、进度、播放条显示屏、主按钮 |
| `--signal` | `#5BD6A0` | 成功状态（success/skipped 色点） |
| `--signal-warn` | `#E3B54F` | 暂停/等待 |
| `--signal-fail` | `#E36C5B` | 失败/错误 |

暗色为默认与唯一主题（SRS FR-WEB-06 允许锁定）。浅色主题以同名变量在 `:root:not(.dark)` 反转，本版只出暗色。

## 3. 字体

| 场景 | 字体 | 字重 |
| --- | --- | --- |
| 标题/正文/按钮 | IBM Plex Sans（fallback：system-ui） | 标题 600、正文 400 |
| 实时数据（速度/ETA/字节/时间） | IBM Plex Mono | 400 |

- 展示与正文同族，不做第二展示族。
- 标题句式（「下载任务」），禁全大写 eyebrow 标签。
- 正文行宽 < 80ch；列表行高 44px 基准。
- 禁在标题中单独强调一个词（斜体/变色）。

## 4. 布局

```
┌──────────┬──────────────────────────────┐
│ 侧栏 224px│ 顶栏：连接状态 · 全局速度      │
│          ├──────────────────────────────┤
│ 仪表盘    │                              │
│ 搜索      │   内容区（左对齐，<80ch）      │
│ 任务      │   列表行式（非卡片网格）        │
│ 历史      │                              │
│ 音乐源    │                              │
│ 设置      │                              │
│ 日志      ├──────────────────────────────┤
│          │ PlayerBar 64px（全局常驻）     │
└──────────┴──────────────────────────────┘
```

- ≥1200px：固定侧栏 + 内容；<1200px：侧栏收汉堡。
- 390px：单列、播放条压缩为封面+播放键、筛选折叠抽屉。
- 内容左对齐；列表行是天然曲目单隐喻，不切卡片。
- meta 信息并列用竖线 `|`，仅真正并列处；禁中点 `·` 串。

## 5. 状态与动效

- 任务状态：色点（8px 圆）+ 文字（`--signal` 成功 / `--signal-warn` 暂停 / `--signal-fail` 失败 / `--ink-mid` 等待）。禁徽章底色块。
- 进度：2px 高进度条，`--accent`，数据驱动平滑推进。
- 动效仅两处：路由切换整体淡入一次（150ms）；进度条 width 过渡。禁逐卡 fade-up、禁悬停阴影。
- 交互反馈（打开抽屉、确认对话框）即时无动画延迟。

## 6. 文案

- 句式、主动词：「下载」「重试失败项」「保存更改」；禁「提交」。
- 空态给动作：「还没有下载任务，去搜索一首。」
- 错误直说原因与修复：「源无法访问：先用该账号加入频道。」
- 全部文案走 vue-i18n（zh-CN 默认）；组件内禁硬编码文案（编码规范 §5）。

## 7. 组件职责（SDD §5.2）

| 组件 | 职责 |
| --- | --- |
| `AppShell` | 侧栏 + 顶栏 + 路由出口 + PlayerBar |
| `PlayerBar` | 全局唯一 `<audio>`；切歌先 `pause()` 再换 `src` |
| `TaskList` | 任务列表行（状态色点、进度条、取消/重试） |
| `HistoryList` | 历史列表行（播放、打开目录、复制路径、编辑标签） |
| `SearchPanel` | 关键词 + 源多选 + 结果列表 + 批量下载 |
| `SourceList` | 源列表 + 添加对话框（链接 → 预览 → 确认） |
| `SettingsForm` | 模板编辑（左编辑右实时预览）+ 并发 + 通知 |
| `TemplateEditor` | 模板 + `preview-path` 实时渲染样例 |

## 8. 工程约束（编码规范 §5 全文有效）

- API 统一 `src/api/client.ts`（fetch 封装：cookie、错误包络解包、401 跳登录）；组件内禁裸 `fetch`。
- SSE 只在 `stores/events.ts` 一处订阅；组件经 store 消费。
- Pinia store `useXxxStore` 命名。
- TS strict、禁 `any`；`defineProps<{...}>` 类型式。
- 组件名 PascalCase 多词；`<script setup lang="ts">`。
- 自定义样式走 CSS 变量 + Tailwind utility；禁行内样式（动态值除外）。
- 时间/大小统一 util：`formatDuration(sec)`、`formatSize(bytes)`、`formatDate(iso)`。
