## 1. 设计定位

**产品**：本地常驻的私人音乐库控制台。**受众**：一个人——自己搭服务器、自己管曲库、关心「文件落在哪儿、标签对不对」的技术型使用者。**主要任务**：把 Telegram 频道里的音频，按自己的命名规则，稳稳落到本机磁盘上，之后还能找到并播放它。

设计隐喻是**调度台**（transfer desk），不是播放器皮肤，也不是仪表盘仪表盘：这一屏的核心信息永远是「现在在搬什么、搬了多少、搬到哪条路径」。所以：

- 视觉身份来自**传输梯级**（segmented transfer ladder）——全站唯一的进度/位置读数装置，出现在任务行、播放条位置、音量三处，同一形状语言。
- 落盘路径是**一级文本**，不是脚注：历史行、仪表盘、设置预览都把路径当主角排。
- 语汇来自主题材本身：频道、消息 id、字节、时长、格式、路径分隔符。

不做：营销 hero、卡片网格、渐变/阴影装饰、彩色徽章、逐卡入场动效、SVG 插画。

## 2. 设计计划与自查修订（两遍式留痕）

第一遍想出的方向，逐条对照「生成式默认答案」清单，凡撞上默认答案的都改掉：

| 第一遍念头 | 撞上的默认答案 | 修订为 |
| --- | --- | --- |
| 近黑底 + 单一酸性强调色 | 默认 #2（近黑 + 荧光绿/朱红） | 深**橄榄石墨**底 `#1A201C`；强调是两盏**语义灯**——琥珀 `#E0A03C`（在传/主操作）与玉色 `#5FBF8E`（完成），不用于装饰；浅色主题是一等公民，不是补丁 |
| 米白纸感 + 衬线标题 + 陶土色 | 默认 #1（暖奶油 + 衬线 + 陶土） | 弃用纸感隐喻；浅色主题是冷调骨白 `#F2F2ED` + 深橄榄墨，字体无衬线 |
| 内容切成一堆等半径圆角卡片 | 默认 #4（SaaS 卡套） | 结构一律**发丝线列表行**与表格；圆角只给输入/按钮（0.25rem），结构面全直角 |
| 仪表盘放三个大数字 + 渐变点缀 | 默认（大数字 + 小标签 + 渐变） | 首屏主角是「正在写入」面板：一条 64 段的传输梯级 + 真实字节/速率/剩余 + 最近落盘路径 |
| 全大写 eyebrow 标签、`·` 连接 meta、按钮结尾加 `→` | 默认 #5（模板化 chrome） | 全部禁用：标题句首字母大写或中文原样；并列 meta 用竖线 `\|`；按钮只写动词，不加箭头（写入编码规范反例表） |
| 01 / 02 / 03 编号标记 | 默认 #5 | 只在初始化向导使用——那确实是两步序列；其余列表不编号 |
| 逐区块 fade-up 入场、悬停加阴影 | 默认动效 | 只保留两处动效：路由内容整体淡入一次（140ms）、梯级宽度/颜色推进；悬停只改背景与前景色 |

**唯一夸张处**（Chanel 的一条建议：出门前摘掉一件配饰）：传输梯级。其余全部克制——没有第二处发光、没有第二套强调色。

## 3. 设计令牌

唯一事实源是 `web/src/app.css`。语义命名沿用 shadcn-svelte（`background/foreground/primary/border/ring…`），因此 `src/lib/components/ui/*` 无需改动即继承本设计语言。

### 3.1 颜色

| 令牌 | 深色（`.dark`，默认） | 浅色（`:root`） | 用途 |
| --- | --- | --- | --- |
| `--background` | `#1A201C` | `#F2F2ED` | 页面底 |
| `--card` | `#222923` | `#FFFFFF` | 播放条、浮层等唯一"抬起"的表面 |
| `--foreground` | `#E9E9DF` | `#1B211C` | 主文本（骨白/墨） |
| `--muted-foreground` | `#9AA69C` | `#5D6A60` | 次文本、标签 |
| `--border` / `--rule` | `#343D35` / `#333D36` | `#D5D9CF` / `#C8CEC2` | 控件边框 / 表格与分区发丝线 |
| `--primary` | `#E0A03C` | `#8A5410` | 在传、主按钮、当前页标记、焦点环 |
| `--lamp-done` | `#5FBF8E` | `#1C7A4E` | 成功/跳过 |
| `--lamp-fail` | `#DC7159` | `#B23A22` | 失败 |
| `--lamp-wait` | `#C9A55F` | `#7D6236` | 暂停、待确认 |
| `--lamp-idle` | `#7B8A7F` | `#78857B` | 等待、未知 |

规则：颜色只表达**状态**或**层级**，不表达装饰。页面里不得出现设计令牌以外的颜色（含 Tailwind 调色板类如 `bg-red-500`）。

### 3.1.1 落盘路径的排法

路径是产品承诺的物证，列表行里按 `splitPath()` 拆成「目录」+「文件名」两段：目录段 `truncate`（可被省略），文件名段 `shrink-0` 且永不被截断——扩展名是曲库的判断依据，不能被省略号吃掉。整条路径始终挂 `title` 属性，悬停可取全量，复制路径按钮给的是原文。

### 3.2 字体

| 场景 | 字体 | 说明 |
| --- | --- | --- |
| 全部拉丁与数字（标题、正文、按钮） | **Archivo Variable**（100–900） | 通过 `@fontsource-variable/archivo` 自带，不外链 CDN |
| 中文 | 系统 CJK（PingFang SC / 微软雅黑 / Noto Sans SC） | 不引入 CJK webfont：自托管与局域网离线优先，体积与延迟不值当 |
| 数据（id、路径、字节、时长、速率、日期、日志） | **DM Mono** 400/500 | 数字等宽是对齐的前提，不是风格选择 |

全站只有两个字族，且它们的差异（grotesque vs mono）明确对应「界面文字」与「机器数据」的分工：`.tabular` 工具类 = DM Mono + `tabular-nums`。

### 3.3 排版尺度

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `text-micro` | 11px / 1.35 | 次级 meta、单位、列表第二行 |
| `text-small` | 13px / 1.5 | 正文默认、表格、按钮 |
| `text-body` | 15px / 1.6 | 段落、小节标题 |
| `text-title` | 22px / 1.2，-0.015em | 页面标题 |
| `text-display` | 36px / 1.05，-0.03em | 保留给"一个屏只有一个数"的场景 |

行宽上限 80ch（`max-w-[56ch]`~`80ch`）；中文段落略窄。半径尺度由 `--radius: 0.25rem` 派生（`rounded-sm/md/lg`）。

### 3.4 动效令牌

- 路由内容淡入：`@keyframes route-fade` 140ms，`ease-out`，仅 `opacity`。
- 梯级推进：`background-color` / `opacity` 120ms linear。
- 总量未知的传输：左端 15% 游标 `ladder-pulse` 1.6s 呼吸，表示「在动但算不出百分比」。
- `prefers-reduced-motion: reduce` 时以上全部关闭（含 shadcn 自带的过渡）。

```
│ 音乐源 │ │ ─────────────────────────────────────── │  │

└───────────────────────────────────────────────────────┘
```

- **侧栏 208px**（≥1024px 固定；更窄收进顶栏汉堡抽屉）。导航项 36px 高、左对齐，当前页由左侧 2px 琥珀条 + 提亮文字标记，不用填充药丸。
- **会话仪表行 44px**：连接灯、账号、在传数、总速率、外观开关。全站唯一，不随路由变化。
- **内容区**：`max-w-[1100px]`，左对齐，`px-4 / lg:px-8`；列表行以发丝线分隔，数值列右对齐等宽。
- **播放条 64px**：全站唯一填充表面（`--card`）。曲目信息 224px 固定宽 → 控制键 → 当前时间 → 梯级（可拖动，`input[type=range]` 透明覆盖，键盘可达）→ 总时长 → 音量梯级（≥1024px）。390px 宽时压缩为：曲目 + 播/停两键。
- **390px 验收**：单列、无横向滚动；筛选条换行；表格的次级列按 `sm/md/lg` 逐级隐藏；弹层全宽。

## 5. 状态、反馈与可访问性

状态一律「**灯 + 词**」（8px 圆点 + 文字），禁止彩色徽章块：

| 后端状态 | 灯色 | 词（zh-CN） |
| --- | --- | --- |
| `queued` | idle | 等待 |
| `downloading` | primary（live） | 下载中 |
| `paused` | wait | 已暂停 |
| `success` / `skipped` | done | 完成 / 跳过 |
| `failed` | fail | 失败 |
| `cancelled` | idle | 已取消 |

映射表只有一处实现：`web/src/lib/tone.ts`（`taskTone()`），页面不得自行发明颜色。

- **进度**：一律用 `Ladder`。任务行 8px、播放条 16px、音量 12px；比例由 `progressRatio(done,total)` 计算，未知总量走不确定态，绝不假装 0%。
- **行内反馈**：操作结果紧贴触发控件，用 `Note`（左侧 2px 色条）呈现，不用 toast。错误说清原因与修复，成功说清改了什么。
- **可访问性**：可见键盘焦点（`outline: 2px solid var(--ring)`）；梯级在可交互时是真 `<input type="range">`（带 `aria-label`）；纯展示时 `role="img"` + `aria-label`；图标按钮一律 `aria-label`；连接状态不只靠颜色（灯 + 词）。
- **动效克制**：见 §3.4；没有一处动效是"为了显得活"。

## 6. 文案

文案是设计内容，不是装饰。规则：

1. 主动词、说结果：按钮「保存更改」→ 提示「已保存」；「加入队列」→「已加入 2 项」；禁「提交」。
2. 空态是邀请：说清下一步动作（「队列是空的。在搜索页下载，或把链接粘到下面。」），并给出出口按钮。
3. 错误说原因与修复，不道歉、不含糊：「源无法访问：先用该账号加入频道，再重试。」「文件大小不符：期望 … 字节，实收 … 字节」。
4. 术语用**用户视角**的词：音乐源、落盘路径、试听、下载历史；不暴露内部实现（`sync_interval_sec`、`preview_id` 只出现在设置项与技术字段处）。
5. 一个字符串只做一件事；禁止在标题里给单个词加粗/变色来强调。
6. 全部文案走 `t("namespace.key")`（zh-CN 默认，en 备选），组件内禁硬编码；缺键回落英文再回落键名，便于发现漏配。

## 7. 目录与组件职责

```

├── app.css                    # 设计令牌唯一事实源（§3）

│   ├── api/client.ts          # 唯一 fetch 出口：cookie、错误包络、401 归一化

│   ├── format.ts              # formatDuration/formatSize/formatRate/formatEta/formatDate/progressRatio

│   ├── router.svelte.ts       # 8 条静态路由（history API，不引路由库）
│   ├── i18n/                  # messages.ts（zh-CN/en）+ index.svelte.ts（t()）
│   ├── stores/                # events（SSE 单点）、queue（任务快照）、player、session、theme
│   └── components/
│       ├── ui/                # shadcn-svelte 生成物，按需增删，少改
│       └── app/               # 本项目自有件：Rail、StatusStrip、TransportBar、MobileNav、
│                              #   Lamp、Ladder、Note、Field、PageHeader、EmptyState、Link
└── views/                     # 8 个路由视图，与后端 FR 一一对应
```

| 视图 | 职责 | 关键交互 |
| --- | --- | --- |
| `DashboardView` | 当前传输 + 队列事实 + 最近 6 条入库 | 大梯级读数；最近落盘路径 |
| `SearchView` | 已启用源内搜索、源多选、试听/下载 | 试听先取 `preview_id` 再入队播放；行内错误 |
| `TasksView` | 队列/进度/失败 | 粘贴链接入队（逐条报错）、暂停/继续/取消、重试失败项 |
| `HistoryView` | 已入库曲目与落盘位置 | 播放（同队列上下文）、复制路径、重新下载、关键词与状态筛选 |
| `SourcesView` | 音乐源增删改 | 添加、启用/自动同步、回溯对话框、移除确认 |
| `SettingsView` | 落盘命名 + 并发/缓存 + 界面偏好 | 模板实时预览、语言与外观（本机存储） |
| `LogsView` | 连接期间的错误事件 | 清空；刷新即清（不假装是历史日志） |
| `SetupView` | 初始化向导（两步，故允许编号） | 密钥校验态清单、发码/登录、完成后进入控制台 |

播放条是全站唯一 `<audio>`：切歌先 `pause()` 再换 `src`（SDD §5.4）；试听与下载互不阻塞（FR-PLAY-03）。

## 8. 工程约束

- 组件 `<script lang="ts">`，Svelte 5 **runes**（`$state/$derived/$effect/$props/$bindable`）；禁 `on:click` 旧语法。
- TS `strict`，禁 `any`（确需用 `unknown` + 收窄）。
- API 调用只经 `src/lib/api/client.ts`；组件内禁裸 `fetch`。
- SSE 只在 `stores/events.svelte.ts` 订阅一次；组件经 store 消费。
- 任务列表事实源是 DB（`GET /api/downloads`），SSE 只作失效信号（收到 `task.status` 即重取，另有 10s 兜底轮询）。
- 样式：Tailwind utility + 设计令牌；禁行内样式（动态尺寸/颜色除外）；禁令牌外颜色。
- 组件命名 PascalCase 多词；`ui/` 为 shadcn-svelte 生成物（可改样式、勿改 API）。
- 时间/大小/速率一律走 `lib/format.ts`；状态词一律走 `statusText()`。
- `npm run lint`（eslint + svelte-check）与 `npm run build` 必须干净。
- 令牌里的 `--meter-on` 同时是任务进度、播放位置、音量三处的填充色；三处都走 `Ladder`，不另写进度条。
- 形状语言只有两种圆角：结构面 0（`border`/`divide` 直角），控件 `--radius`（0.25rem 派生）。
