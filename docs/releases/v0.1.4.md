# v0.1.4 密钥文件搬进数据目录，容器重建不再重走向导

现场表现是：`docker compose up -d` 之后 `app.db` 和 `sessions/` 都还在，却要重新走一遍初始化向导。丢的不是数据，是**密钥文件的位置**：它写在 `TGM_BASE_DIR/config.yaml`，而 compose 只把 `./data` 挂成 `/data/data`——`/data/config.yaml` 是 `/data` 下唯一没被挂出来的文件，躺在容器可写层里，容器一重建（改了 compose、拉了新镜像、`down` 后再 `up`）就跟着没了。放行判据是「密钥齐备 + 已登录」，密钥没了，数据库再全也进不去。

- **密钥文件收进数据目录**：位置改为 `<TGM_BASE_DIR>/data/config.yaml`（Docker 即宿主机 `./data/config.yaml`），与 SQLite、会话、中转、日志**同一个卷**。不必为它单独挂 bind mount，也就没有「宿主机文件忘建 → Docker 把它建成目录 → 应用读文件直接报错」那个坑
- **向导首次保存即自动创建**（父目录按需 `mkdir`），不需要预先 `touch`
- **旧位置自动迁移**：启动时把 `<TGM_BASE_DIR>/config.yaml` 搬进新位置。搬而不是拷——两个位置并存会让「向导到底写哪个」变成猜谜；跨挂载点搬不动（比如你之前手动挂过 `./config.yaml`）时只告警，读取仍按旧位置兜底，向导保存会写新位置
- **compose 少一行挂载**：`./data` 一个卷装下密钥 + SQLite + 会话 + 中转 + 日志，`./downloads` 留给曲库
- **纯环境变量部署**：同名 `TGM_*` 变量优先级高于文件，给全了（`TGM_API_ID` / `TGM_API_HASH` / `TGM_BOT_TOKEN` / `TGM_WEB_LOGIN_SECRET` / `TGM_CHKSZ_API_KEY` / `TGM_PROXY_HOST` / `TGM_PROXY_PORT` / `TGM_*_DIRECTORY`）就完全不需要这个文件，`config.yaml.example` 文末列全了
- **启动闸门日志给出路**：绑 `0.0.0.0` 且没有 `web_login_secret` 会拒绝启动，现在拒绝日志（stderr 与 `data/logs/app.log`）直接写出要改的配置文件路径、等价的 `TGM_WEB_LOGIN_SECRET`、以及显式放行的 `TGM_WEB_LOGIN_ENABLED=false`——只报「拒绝」不给出路的日志，在 Docker 里等于让人去翻源码
- **敞开的面板留痕**：`TGM_WEB_LOGIN_ENABLED=false` 且绑 `0.0.0.0` 时不拦启动，但记一条 warning，日志里能分清「有意为之」与「漏配口令」；本机 `127.0.0.1` 免密是设计内的，不刷这条
- **发版不再重复构建**：main 每次 push 多推一个 `:sha-<完整提交>` 标签；打 `v*` 标签时若该提交的镜像已在（⇒ 已经在 main 上过了 test + build + smoke），CI 只把它 retag 成版本标签（`docker buildx imagetools create`，几秒），test/build 整体跳过。`git push` main 与 `git push` 标签是两个独立的 push 事件，GitHub 不会因为指向同一提交而合并，省时间只能靠复用；标签打在没推过 main 的提交上时自动退回完整流水线，不会发布未测代码
- **测试**：`tests/unit/test_config.py` 新增「密钥文件落在 `data/` 下」「旧位置读得到、启动时被搬走（含幂等与不覆盖新文件）」；`tests/api/test_api.py` 的落点回归改到新位置，并新增「拒绝提示点名三条出路」「0.0.0.0 关登录要告警、127.0.0.1 不刷屏」

升级不用手工搬文件：下次启动会自动迁移，日志里有一条 `config.yaml 已迁移`。如果你之前为了绕开这个问题手动挂过 `./config.yaml`，把那行挂载删掉再重启——跨挂载点搬不过去，日志会有告警（读取照常）。

## 镜像

```bash
docker pull ghcr.io/kato358/telgram_musicdown:0.1.4
docker pull ghcr.io/kato358/telgram_musicdown:0.1
```

`:latest` 仍跟着 `main`；`:0.1` 随本条移动到 0.1.4。要锁版本就把 compose 里的 `image:` 钉到 `:0.1.4`。
