# v0.1.1 主题过渡、播放器起始态与窄屏修复

明暗切换不再是一帧硬切：切主题那一瞬给 `<html>` 挂一次 240ms 的颜色过渡，之后摘掉——不常驻，免得与 hover、路由进场的既有动效抢同一批属性。顺带修掉跟随系统时的首帧翻转：深色系统下原来会先按浅色落一次、再由 `start()` 翻回深色。

- **播放器起始收起**：右下角平时只有一枚 86×68 的封面片（没在响就不占版面），起播即展开；暂停**不**收起（收起来就没有「继续」可点），折叠把手仍可手动开关
- **仪表盘横幅搜索框（窄屏）**：纵向表单里 `flex-1` 的 `flex-basis: 0` 会盖掉 `height`，40px 胶囊实测被压成 21px 的细片 → 改 `h-10 w-full … sm:flex-1`；队列卡的入队框是同一处事故（实测 31px），一并收口
- **下载页记录表（窄屏）**：页签 / 重试 / 搜索从固定 56px 高、不换行的卡头迁进工具带并换行排——原先四个药丸被压成一列、搜索框叠在它们身上；批量条改挂同一带的第二行
- **CI**：打 `v*` 标签后自动建 GitHub Release，正文取仓库里的 `docs/releases/<标签>.md`（这条就是本文件）；文件不在则退回 GitHub 自动生成的 release notes

实测与取舍记账见《前端设计规范》v3.26 §0.20 / §5.3 / §5.4.2 / §5.6 / §7。
